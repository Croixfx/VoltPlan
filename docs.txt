Build a professional Flutter mobile application called **VoltPlan**.

VoltPlan is an AI-assisted electrical planning and estimation app for building professionals.

## Important scope

This is a real commercial mobile application, not a toy/demo.

For this first implementation, focus on **UI/UX and frontend architecture only**.

Do NOT implement:

* Architectural floor-plan editing
* CAD functionality
* Manual electrical drawing/editing
* Real AI integration
* Real electrical calculations
* Backend APIs
* Authentication backend
* Payment systems

Use realistic mock data and structure the code so these capabilities can be integrated later.

## Technology

* Flutter
* Dart
* Material 3
* Responsive mobile-first design
* Clean feature-based architecture
* Reusable components
* Proper navigation
* Dark/light theme support if practical

## Product concept

The user workflow should be:

Dashboard
→ Create Project
→ Upload Architectural Plan
→ AI Analysis
→ Electrical Recommendations
→ Electrical Plan
→ BOQ
→ Cost Estimate
→ Report

The uploaded architectural plan is VIEW-ONLY.

There is no floor-plan editing in this version.

The app should feel like a real professional engineering product.

Use:

* Bottom sheets

* realistic residential projects
* realistic electrical materials
* realistic quantities

## Important

Do not build a fake AI system that pretends to actually analyze an uploaded architectural drawing.

For this version, simulate the analysis using mock data while keeping the code structured so a real backend/API can replace the mock service later.

The final result should look like a polished commercial mobile application that is ready for the next development phase.
